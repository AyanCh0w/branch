Set up Branch for Mac

Send new replies from a ChatGPT conversation to your team’s Branch board.

Install Branch for Mac

On a work Mac, look for Branch for Mac in your company’s software catalog or ask IT to install it. Requires macOS 14 or later.

Open the download and drag Branch for Mac into Applications. Requires macOS 14 or later.

Download Branch for Mac

Connect a ChatGPT conversation

  1. Open your board, then select ChatGPT sync → Connect ChatGPT to this board.
  2. Choose the conversation in Branch for Mac. If macOS asks, allow Branch for Mac in Accessibility so it can read completed replies.
Open your board ↗

When Branch says Sync is on, new completed replies will appear in Context. Anyone with access to the board can read them.

You can switch chats. If Branch says Waiting for your chat, return to the connected conversation in the same ChatGPT window to resume syncing.

Stop syncing or reconnect

Choose Stop syncing in the Mac app or Disconnect ChatGPT chats on the board. To reconnect, keep your ChatGPT conversation open and start again from the board.
