If you need to install or update the Mac app, use the setup instructions below.

First time? Install with your agent.

Copy the setup handoff into your agent on your Mac. It includes the app source, build steps, permissions, pairing, and a live connection test.

Developer preview · macOS 14+ · Built locally with Swift 6.1+. A signed, notarized installer is not available yet.

  1. Install the companion.

    Your agent checks this Mac, tests the app, and builds it from the Branch source. Without a signing identity, the preview is called Branch Desktop Probe.

  2. Choose what to share.

    Open the app and approve Accessibility when macOS asks. This permission lets the app read screen text. Start the connection from your Branch board and choose the ChatGPT conversation you want to sync. People with access to that board can read saved replies.

  3. Watch a new reply arrive.

    Wait for Connected, send a new message in ChatGPT, and open your board’s Context view. The completed reply should appear without a refresh. Earlier chat history is not imported.

Already installed, or need help?

Open the Mac menu-bar app, select ChatGPT Sync, and it will find your conversation automatically. If needed, click Refresh list. Choose your conversation and click Connect chat.

If a security warning or system authentication blocks setup, stop and review it yourself. Do not disable macOS protections. The compatibility probe checks what ChatGPT exposes; it does not install or connect the app.

Use Stop syncing in the Mac app or Disconnect ChatGPT chats in the board to stop future saves. Pair again after quitting the app or when the connection expires.
