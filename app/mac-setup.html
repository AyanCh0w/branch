Set up Branch for Mac

Send new replies from the ChatGPT desktop app to your team’s Branch board.

Install Branch for Mac

On a work Mac, look for Branch for Mac in your company’s software catalog or ask IT to install it. Requires macOS 14 or later.

Open the download and drag Branch for Mac into Applications. Requires macOS 14 or later.

Download Branch for Mac

Connect a conversation

  1. Use Agents on your board for direct agent access. If you already use the Mac companion to sync chat replies, use the link below to open it from your board.
  2. Choose the open conversation in Branch for Mac and click Connect conversation. If macOS asks, allow Branch for Mac in Accessibility so it can read completed replies.
Continue to Branch ↗

When Branch says Sync is on, new completed replies will appear in Context. Anyone with access to the board can read them.

You can switch chats. If Branch says Waiting for your chat, return to the connected conversation in the same window to resume syncing.

Stop syncing or reconnect

Choose Stop syncing in the Mac app or Disconnect previous chats under the board’s Agents settings. To reconnect, keep your conversation open and start again from the board.
