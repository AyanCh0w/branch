Move a card
Drag its header. Resize from the bottom-right corner.
Carry context
Pull a card’s right-hand nib to a chat. Release in empty space to branch.
Branch a sentence
Select text, then pull it out. Option/Alt+Enter works too.
Remove context
Click a source reference, then use its detach control.
Keyboard
N / C / S create cards. F fits the board. ⌘/Ctrl Z undoes. Tab to a nib and press Enter to branch.
